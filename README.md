# Python 201 – Yapay Zeka

Tuncay Erol'un **Yapay Zeka 201 (Python)** kursunu takip ederken yazdığım kodlar ve denemeler.

## İçerik

| Dosya | Konu |
|---|---|
| `app.py` | YOLOv8 ile görüntü üzerinde nesne tespiti (Ultralytics), sonucu OpenCV ile gösterme |

## Kurulum

```bash
pip install ultralytics opencv-python
python app.py
```

> Model dosyaları (`yolov8n.pt` vb.) repoya eklenmedi; Ultralytics ilk çalıştırmada otomatik indirir.

## Kullanılan teknolojiler

- Python 3.10
- Ultralytics YOLOv8
- OpenCV
